# Repository context map

This file answers two questions about `lsei-lunar-scenario-explorer`: what is public, and where did
it come from. FILES declares the pushed tree, one row per file, checked bidirectionally against the
tree on disk by `tools/repo_map_check.js`: every staged file has a row (the leak direction) and every
row has a staged file (the phantom direction). EXCLUDED names the negative space, the project sources
that do not ship, each with its own ruling. Neither table is consulted by the report generator prompt
at generation time; the app's own `KNOB_DATA.SLUGS` is the generator's sole identity source. This map
is an audit artifact for a human reader.

Table dialect: one record per physical line, no wrapped cells, a literal `-` for an empty cell, and
`&#124;` for a pipe inside a cell.
